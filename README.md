# 无损传达 Skill

一套给普通 AI 用户和创作者使用的沟通指南，帮助你把还没说清的想法变成可以检查、修正并交给 AI 继续执行的要求。

你可能说“简单一点”，AI 却理解成“少放几个按钮”，结果反而不知道下一步该做什么。无损传达会引导 AI 先展示它的整体理解，再根据你的反馈修正关键部分，并把已经确认的内容整理出来。

## 一、这个项目是什么？

无损传达 Skill 是一套供 AI 工具加载使用的操作指南。Skill 就像给 AI 的工作方法说明，告诉它遇到重要歧义时怎样展示理解、听取反馈、修正方向，并交接已经确认的要求。

你只需要用自己的话描述目标，必要时补充文件或示例。AI 会按本 Skill 的规则区分你明确提出的要求和它暂时作出的猜测，再用一个具体小样帮助你判断双方是否理解一致。它主要针对“脑子里有想法，却很难一次说清”以及“AI 说懂了，做出来却偏了”的情况。

它不是独立软件、网站或常驻后台服务。你需要在支持 Skill 的 AI 工具中安装或加载它；实际是否自动调用，仍由该工具决定。

## 二、先看效果

仓库没有真实运行截图、视频或独立模型评测。下面是产品说明中的**文字示意**，用来解释工作方法，不是某次 AI 实际运行的记录。

**用户输入：**“帮我设计一个文件整理工具，界面简单一点。”

**AI 可以先这样展示它的理解：**

> 我理解你想让用户导入文件、确认整理方式，再查看整理结果。这里我暂时把“简单”理解为操作步骤少；这次的小样只说明流程，不代表已经有真实的文件整理功能。你更在意步骤少，还是每一步都能看懂下一步会发生什么？

看点是：AI 把“简单”具体化，并把假设标出来。你可以回答“步骤可以多一点，但每一步要讲清楚”，AI 再修正理解。小样只是帮助讨论，不能证明未来做出的界面或功能已经正确。

## 三、适合谁用？

### 特别适合

- 经常把内容、设计、工作流程或产品想法交给 AI，却很难一开始就说完整的人。
- 不熟悉专业术语，希望先看一个具体例子，再指出哪里不符合想法的创作者或 AI 工具使用者。
- 需要把讨论过的目标、限制和未定事项整理好，接着交给原来的 AI 或其他专业工具处理的人。

### 不适合

- 想单独下载一个应用，让它自动整理文件、制作图片或开发产品的人；本项目不直接执行这些工作。
- 需要 AI 保证每次都完全理解、自动记住所有对话，或替你确认最终成品的人。
- 使用的 AI 工具不支持 Skill，也不允许在对话中提供这类操作指南的人。可以手动粘贴规则尝试，但那不等同于安装或自动调用。

## 四、你会得到什么？

一次使用通常会在 AI 对话中得到一个可供判断的整体小样、对反馈的简短归纳，以及必要时的一份需求共识摘要。摘要可以记录目标、已确认的决定、重要限制、尚未确定的事项和下一步交接内容。

仓库还提供 Markdown 格式的共识单模板：[需求共识单](lossless-intent/assets/consensus-template.md)。它只是模板，不会自动替你创建文件；如果需要保存，可以明确让 AI 按模板整理，并指定保存位置。最终产物仍取决于你使用的 AI 工具及其获授权的文件操作能力。

## 五、它能帮你解决什么问题？

原来的做法可能是反复改写“自然一点”“高级一点”或“简单一点”，但双方仍然没说清这些词具体代表什么。使用本 Skill 后，AI 会把重要理解变成可见的小样，你可以直接指出差异，避免只围绕形容词来回猜。

反馈后，AI 应说明保留了什么、修正了什么、还有什么没确定，并在交接时带上已经确认的要求。你仍然需要判断小样是否接近目标，也要检查后续制作出来的真实内容；本 Skill 不替你验收成品，也没有经过对照实验来证明节省了多少时间或返工。

## 六、安装与快速开始

### 使用前需要准备

- **必需：**支持加载 Agent Skills 的 AI 工具；以及解压 ZIP 文件的工具。本包没有声明 AI 工具的最低版本要求，请确认你使用的版本支持 Skill。
- **下面的安装步骤：**以 Windows 版 Codex 为例；其他系统或 AI 工具请按其官方 Skill 安装说明操作。
- **不需要：**为本 Skill 单独配置数据库、API 密钥或联网服务。
- **可能产生的费用：**本包不附加收费服务；你使用的 AI 工具可能按其自身账户或套餐规则计费。

### 推荐方式：在 Windows 版 Codex 中安装

1. 下载仓库里的 [lossless-intent-v1.0.0.zip](dist/lossless-intent-v1.0.0.zip)，解压后找到 `lossless-intent` 文件夹。
2. 在文件资源管理器地址栏输入 `%USERPROFILE%\.agents\skills\`。如果文件夹不存在，可以按这个路径逐层创建。
3. 把整个 `lossless-intent` 文件夹复制到 `skills` 里面。完成后应能找到：

   ```text
   %USERPROFILE%\.agents\skills\lossless-intent\SKILL.md
   ```

   只复制 `SKILL.md` 不够，其他说明和参考文件也需要一起保留。若目标位置已经有同名文件夹，先检查并备份旧版，不要直接覆盖。

4. 重新打开 Codex；如果它没有识别，可以重启 Codex 后在对话中输入 `/skills` 查看，或直接尝试下面的 `$lossless-intent` 调用。

### 第一次使用

在 Codex 新对话中复制这段示例：

```text
$lossless-intent 我想设计一个整理文件的工具。我还没想清楚“简单好用”具体是什么。先给我一个从导入到查看结果的整体小样，把我明确说的内容和你的暂时假设分开；这次只帮我对齐需求，不要实际整理或改动文件。
```

如果安装和调用正常，AI 会在对话中展示对目标的理解、一个可判断的小样、暂时假设和本轮要确认的重点。这里的文件整理只是讨论示例，不会因为安装本 Skill 就自动获得文件整理能力。

## 七、如何使用？

最常见的用法是先自然地说出你想完成的事情，不必先写成专业需求文档。遇到会明显影响结果的歧义时，让 AI 展示一个整体小样；然后指出要保留、修改或补充的地方。目标已清楚的小修改可以直接提出，不需要每次都重新澄清。

在 Codex 中可以明确写 `$lossless-intent`；在 Claude Code 中可以使用 `/lossless-intent`。某些兼容工具也可能按 Skill 描述自动调用，但是否触发由宿主工具决定，不能只凭回答看起来相似就认定已加载。

你也可以在已有任务中继续使用，例如：

```text
用无损传达检查当前方案与我们已经确认的要求有哪些偏差。保留没有变化的决定，只对真正改变的部分重新对齐。
```

本 Skill 默认利用当前对话和你提供的材料，不会自动把整段聊天永久保存，也不会自动同步到其他 AI 工具。需要交给另一个工具时，可以要求它按共识模板整理必要信息，再由你决定保存或提供给谁。

## 八、项目工作流程

```text
你描述想法 → AI 展示整体小样并标出假设 → 你指出差异 → AI 修正并回放共识 → 你检查后交给后续执行
```

AI 负责展示理解、记录必要的反馈并整理交接内容；你负责判断示例是否接近想法、补充关键要求，并检查真实产物。只有在目标、限制或已确认决定发生重大变化时，才需要重新对齐受影响的部分。

## 十、注意事项与常见问题

- “无损”是项目名称和努力方向，不代表能百分之百还原想法或保证零返工。
- Skill 的自动加载、文件访问和生成能力取决于你使用的工具及其设置；本包不会替宿主工具增加权限。
- 小样是帮助检查理解的材料，不等于真实界面、代码或成品已经完成并通过验收。
- 仓库当前没有 `LICENSE` 文件。许可证没有明确前，不能据此判断是否允许复用、修改或商业使用；因此 README 不展示许可证徽章。
- ZIP 包附带的验证记录显示，包结构等静态检查曾通过；24 个独立模型行为用例、宿主自动触发和安装效果均未运行。详见[验证记录](docs/lossless-intent-validation.md)。

### 常见问题

**输入 `$lossless-intent` 后提示找不到 Skill** → 可能是文件夹多套了一层、只复制了 `SKILL.md`，或工具尚未重新识别。检查文件是否位于 `%USERPROFILE%\.agents\skills\lossless-intent\SKILL.md`，并重启 Codex。

**AI 没有自动按 Skill 的方式回应** → 自动调用由宿主决定，不保证每次触发。可在支持的工具中明确使用 `$lossless-intent` 或 `/lossless-intent`；如果工具不支持 Skill，则需按其规则手动提供指令。

**我以为它会直接生成文件或保存共识** → 本 Skill 本身只提供协作规则和模板。请明确告诉 AI 要生成什么、保存到哪里；实际文件操作仍取决于宿主能力和你的授权。
